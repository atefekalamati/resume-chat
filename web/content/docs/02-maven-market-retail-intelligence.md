# هوش تجاری فروشگاه زنجیره‌ای Maven Market

## خلاصه
**فارسی:** یک مدل ستاره‌ای و داشبورد ۶ صفحه‌ای Power BI برای یک فروشگاه زنجیره‌ای با ۲۴ شعبه در آمریکا، مکزیک و کانادا. مهم‌ترین یافته: بیشتر رشد ظاهری فروش از افتتاح شعب جدید بود، نه از بهتر فروختن شعب قدیمی.

**English:** A star-schema model and 6-page Power BI dashboard for a 24-store chain (USA, Mexico, Canada, 1997–1998), with 63 DAX measures validated 124/124, 173 tests, and a set of T-SQL queries validated on SQL Server. Key insight: reported growth of +112% was mostly new stores; same-store growth was only +8.4%.

## مسئله و هدف
- رشد فروش واقعی است یا فقط از شعبه‌های جدید آمده؟
- حاشیهٔ سود، سهم مشتریان پرارزش و اثر کارت عضویت چیست؟
- مرجوعی‌ها کجا بیشتر است؟
- آیا شعبهٔ بزرگ‌تر فروش بیشتری دارد؟

## سؤال‌های متداول (برای چت‌بات)
**مهم‌ترین یافتهٔ این پروژه چیست؟**
فروش ۱۱۲٪ رشد کرد، اما رشد شعب یکسان فقط ۸٫۴٪ بود. بیشتر رشد از ۱۱ شعبهٔ جدید آمد.

**Same-Store Sales یعنی چه؟**
مقایسهٔ فروش فقط شعبه‌هایی که در هر دو دوره باز بوده‌اند، تا اثر افتتاح شعبهٔ جدید حذف شود.

**مدل داده چه شکلی است؟**
مدل ستاره‌ای با ۲ جدول واقعیت (فروش، مرجوعی) و ۴ بعد (تاریخ، مشتری، محصول، شعبه).

**درستی اعداد چطور بررسی شد؟**
۱۲۴ بررسی برای معیارهای DAX، ۱۷۳ تست خودکار، و اجرای کوئری‌های SQL روی SQL Server.
